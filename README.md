# English Journey Vocabulary

Recurso interactivo compatible con GitHub Pages y Azure Static Web Apps.

- Filtros por nivel, subnivel y unidad.
- Audio con SpeechSynthesis a 1x, 0.85x y 0.75x.
- Flashcards aleatorias con giro y traducción.
- Datos en vocabulary.json para reemplazo posterior por datos generados desde Microsoft Lists.

Archivos de entrega TXT: contienen una copia separada de index.html, style.css, script.js y vocabulary.json.

- Adivina mis flashcards: usa las palabras seleccionadas al iniciar, muestra el significado y permite escribir o revelar la respuesta, con puntuación final.
- Los botones del juego usan velocidades explícitas; las tarjetas respetan el selector de velocidad.
